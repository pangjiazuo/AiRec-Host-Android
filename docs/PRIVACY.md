# 人脸与车牌马赛克

在每一路的录像设置中，可以分别开启“车牌马赛克”和“人脸马赛克”。默认关闭，确认提示并保存后生效；可应用到其他通道。

实际处理由安卓录像主机完成，客户端只负责设置和播放。预览、事件截图和新录像使用同一套遮挡。已有录像不会改变，新录像中的马赛克无法去掉。旧主机没有此功能时请先升级。

**开启后会严重降低性能。** 1.0.5 改为间隔定位、逐帧图像跟踪；单路两项同时开启的完整录像平均约 22 帧/秒，仍使用 NPU 检测、GPU 马赛克和硬件 H.264 编码。详细验收见 [测试记录](VERIFICATION.md)。五路实拍尚未验证。

单路约每 500 毫秒重新定位，两次定位之间使用当前图像跟踪遮挡位置；多路同时开启时增加定位间隔。快速新目标可能短暂漏遮挡，这是为提高录像帧率作出的取舍。

检测失败或超时输出黑画面并记录错误。小目标、侧脸、遮挡或特殊车牌可能漏检，不能保证所有敏感区域都能识别。YOLO 在处理后的预览帧上识别人、车和动物。

## 源码构建需要的 SDK

使用 RK3399PRO Android 版 RockX 的人脸、车牌定位模型，不进行身份识别或车牌文字识别。说明见[厂商 API](https://t.rock-chips.com/wiki/rockx_api_doc/)。

本地验证已准备运行库和模型。仓库不包含这些厂商文件：其许可没有明确授予公开再分发权，发布包含 SDK 的 APK 前也需确认厂商授权。

拿到有权使用的兼容 SDK 后，执行以下命令，再按 README 构建。脚本会校验与本次实测版本一致的文件哈希。

```powershell
.\scripts\prepare-privacy-sdk.ps1 -SdkDirectory 'D:\RockX_SDK\sdk'
.\scripts\build.ps1
```
